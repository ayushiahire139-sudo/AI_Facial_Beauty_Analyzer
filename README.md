# AI Facial Beauty Analyzer

An AI-powered facial analysis application that analyzes facial features from uploaded images and generates a detailed facial analysis and beauty report.

## Features

- Face detection
- Facial landmark detection
- Facial feature analysis
- Eye analysis
- Lip analysis
- Nose analysis
- Jaw analysis
- Face shape detection
- Skin tone analysis
- Facial symmetry analysis
- Golden ratio analysis
- Emotion detection
- Beauty score calculation
- Beauty report generation
- User registration and login
- REST API using FastAPI
- Web-based frontend

## How It Works

1. User uploads a facial image.
2. The backend receives and processes the image.
3. Face detection is performed.
4. Facial landmarks are detected.
5. Facial features are analyzed.
6. Facial measurements are calculated.
7. A beauty score and analysis are generated.
8. A detailed report is created.
9. Results are displayed through the web interface.

## Backend

The backend is developed using FastAPI and provides REST API endpoints for user authentication, image processing, facial analysis, and report generation.

## Frontend

The frontend provides a web interface for user registration, login, image upload, and displaying facial analysis results.

## Database

SQLite is used for storing user information and application data.

## Project Goal

The goal of this project is to develop an AI-based facial analysis system that combines computer vision, machine learning, and web technologies to provide automated facial analysis and personalized insights.
